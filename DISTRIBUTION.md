# Distribution

The native Windows `owscout.exe` this file used to document is **retired**.
The browser capture app at `docs/capture/` (zero-install, runs in any modern
browser via `getDisplayMedia` + tesseract.js) is the only supported capture
path — see `FEATURES.md` §2.7 for what replaced it.

The exe's source (`owscout/gui.py`, `owscout_app.py`, `owscout.spec`) still
exists in the repo but is unmaintained and not distributed. The old
Defender/SmartScreen/signing guidance that used to live in this file is
preserved in git history if it's ever needed again.
