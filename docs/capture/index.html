Zero-install scouting: share your whole screen (Overwatch borderless/fullscreen, 16:9), calibrate once, then capture each map's comps round-by-round. Runs entirely in your browser.
How it works — 30-second guide
1Open a replay
Run Overwatch borderless/fullscreen (16:9) with a replay open.
2Share screen
Share my screen → pick your whole screen (best for auto-calibrate; a single window includes the title bar).
3Calibrate
Auto-calibrate aims the boxes at the 10 portraits, shows you the confidence, and you confirm (want ~10/10). Or set the LEFT/RIGHT boxes by hand.
4Pick a code
Pick a replay (filter by division / opponent), Copy code, paste it into Overwatch and load it. Done maps drop off; a = someone's scouting it now.
5Capture
Press Snapshot — the first press per map auto-detects which team is on the left and tags players from the HUD names; if it can't tell, it'll say so and ask you to set the LEFT team / Swap teams before it captures anything. Then: Next round, Attacking picker (escort/hybrid — round 3+ needs a click, it's time-bank not parity), Sub-map (control). Control panel = no alt-tab; keys S/R/Z/F.
6Publish
Finish + save → auto-fetches the next code. Publish when done; the site updates in ~2 min.

Tips: use borderless, not exclusive fullscreen; re-scouting an already-covered map still adds player data. If a portrait reads wrong or a new hero isn't known, fix it under Hero recognition — it learns for next time. Fix misreads on a saved map with its review button before publishing.

Use Overwatch's default team colors (blue/red) — if your in-game UI colors are customized, accuracy drops noticeably.
