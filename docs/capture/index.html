OW Scout — Capture · browser

Zero-install scouting: share your Overwatch screen (borderless/windowed), calibrate once, then capture each map's comps round-by-round. Runs entirely in your browser.
How it works — 30-second guide
  1. Run Overwatch borderless/fullscreen (16:9) with a replay open.
  2. Share my screen → pick your whole screen (best for auto-calibrate; a single window includes the title bar).
  3. Auto-calibrate ✨ aims the boxes at the 10 portraits and self-tests (want ~10/10). Or set the LEFT/RIGHT boxes by hand.
  4. Pick a replay (filter by division / opponent), Copy code, paste it into Overwatch's replay-code box, and load it.
  5. Snapshot each distinct comp (spawn + key fights). Use Next round, Sub-map (control maps), Flip attack (escort/hybrid) as it changes — or Pop out overlay and do it all without alt-tabbing.
  6. Finish + save the map → it auto-fetches the next code. Publish when you're done; the site updates in ~2 min.

Tips: snapshot at real moments (there's no auto-spam); use borderless, not exclusive fullscreen; re-scouting an already-covered map still adds player data.
