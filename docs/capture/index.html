OW Scout — Capture · browser

Zero-install scouting: share your Overwatch screen (borderless/windowed), calibrate once, then capture each map's comps round-by-round. Runs entirely in your browser.
How it works — 30-second guide
  1. Run Overwatch borderless/fullscreen (16:9) with a replay open.
  2. Share my screen → pick your whole screen (best for auto-calibrate; a single window includes the title bar).
  3. Auto-calibrate ✨ aims the boxes at the 10 portraits and self-tests (want ~10/10). Or set the LEFT/RIGHT boxes by hand.
  4. Pick a replay (filter by division / opponent), Copy code, paste it into Overwatch's replay-code box, and load it. Maps you've done drop off the list; 🔒 means someone else is scouting that one now.
  5. ✨ Auto-detect sides + players reads the HUD names to set which team is on the left and tag each hero with its player (or set the left team by hand / ⇄ Swap teams).
  6. Snapshot each distinct comp (spawn + key fights) — or tick auto-snapshot to read on a timer. Use Next round, the Attacking team picker (escort/hybrid), Sub-map (control) as they change. Pop out overlay to do it all without alt-tabbing; keys S/R/Z/F work when this page or the overlay is focused.
  7. Finish + save → it auto-fetches the next un-scouted code. Publish when done; the site updates in ~2 min.

Tips: use borderless, not exclusive fullscreen; re-scouting an already-covered map still adds player data. If a portrait reads wrong or a new hero isn't known, fix it under Hero recognition — it learns for next time. Fix misreads on a saved map with its review button before publishing.
