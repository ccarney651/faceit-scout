Zero-install scrim scouting: share your whole screen (Overwatch borderless/fullscreen, 16:9), calibrate once, then capture each map's comps round-by-round. Runs entirely in your browser — everything stays private on this machine.
How it works — 30-second guide
1Open a replay
Run Overwatch borderless/fullscreen (16:9) with a replay open.
2Share screen
Share my screen → pick your whole screen (best for auto-calibrate; a single window includes the title bar).
3Calibrate
Auto-calibrate aims the boxes at the 10 portraits, shows you the confidence, and you confirm (want ~10/10). Or set the LEFT/RIGHT boxes by hand.
4Set up scrim
Create or pick a private scrim below, choose a map, and press Start map. A replay code is optional and stays private.
5Capture
Press Snapshot — use the side radios or Swap teams to set which team is on the left. Then: Next round, Attacking picker (escort/hybrid — round 3+ needs a click, it's time-bank not parity), Sub-map (control). Pop out overlay = no alt-tab; keys S/R/Z/F.
6Save
Finish + save — the map is saved privately in this browser. Review, export, or import scrims under the scrim panel.

Tips: use borderless, not exclusive fullscreen. If a portrait reads wrong or a new hero isn't known, fix it under Hero recognition — it learns for next time. Fix misreads on a saved map with its review button.

Use Overwatch's default team colors (blue/red) — if your in-game UI colors are customized, accuracy drops noticeably.
