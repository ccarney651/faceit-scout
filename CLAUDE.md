# CLAUDE.md

**The canonical instructions for this repository live in `AGENTS.md`. Read it
first.** It is the cross-agent standard file, so Claude Code, opencode, Codex,
and Cursor all work from the same context — which matters here, because this
project gets handed between agents.

- `AGENTS.md` — commands, invariants, gotchas, roadmap, conventions.
- `ARCHITECTURE.md` — how every part of the project works and how the parts
  connect. Read it before deep work.
- `CHANGELOG.md` — what changed and when.

Nothing else belongs in this file. Anything Claude-Code-specific worth keeping
should be added here explicitly; everything else goes in `AGENTS.md`, so the two
cannot drift apart.
